# Правила игры

## Основные элементы:
- У игроков 4 фишки и 2 кубика.
- **ТЮРЬМА**: находится в середине поля. Только при броске 6 можно вернуть фишку в руку. При выпадении двух 6 можно поставить фишку на поле.
- **СИЗО**: клетки 5, 4, 3 с каждой стороны. Попадая в тюрьму, игрок должен кинуть соответствующий кубик, передвигаясь по одной клетке. Максимальное заключение — 3 клетки.
- **ХАТА**: возможность попасть в хату открывается после прохождения первого круга.
    - Фишки в хате нельзя сбить.
    - Другие игроки не могут заходить в чужую хату — у каждого своя.
- **ПОДВОРОТНЯ**: каждая **пятая клетка от угла** — **подворотня**.
  - При вставании на клетку подворотни игрок перемещается **в противоположном направлении** на этом же углу.

## Ходы:
- Игра начинается с **нуля**, у каждого игрока своя сторона.
- Для постановки фишки на поле необходимо выбросить **6**.
- Если у игрока нет фишек на поле и он не выбрасывает **6**, он пропускает ход.
- Если у игрока есть фишки на поле и он выбрасывает **6**, у него есть выбор:
    1. Походить (обязательно в порядке убывания чисел на кубике).
    2. Поставить новую фишку.
- При выпадении пары одинаковых значений:
    - Можно передвинуть уже стоящие на поле фишки.
    - Можно кинуть кубики еще раз.
    - Если выпадает **две 6**, игрок может поставить **2 фишки** или походить и бросить кубики еще раз.

## Дополнительные правила:
- Игроки двигаются **по внешнему кругу**.

- Если фишка стоит на поле и другой игрок наступает на неё — фишка отправляется в **ТЮРЬМУ**.

## Победа:
Игрок выигрывает, если заведет **все 4 фишки в ХАТУ**.
