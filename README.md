# Правила игры

Подробный план реализации и история исправлений находятся в [`GAME_REPAIR_PLAN.md`](GAME_REPAIR_PLAN.md).

## Основные элементы

- Игра рассчитана на 4 игроков. У каждого игрока 4 фишки и 2 кубика.
- У каждого игрока своя стартовая клетка `0` и собственная цветная хата.
- Внешний круг состоит из 48 клеток и замыкается после клетки 47.

### Тюрьма

- Центральная тюрьма находится в середине поля.
- Сбитая фишка отправляется в тюрьму и теряет прогресс круга.
- Одна шестёрка возвращает выбранную фишку из тюрьмы в руку.
- Две шестёрки выводят выбранную фишку из тюрьмы прямо на старт.

### Подворотня

- Красные и зелёные дуги соединяют две стороны каждого угла, как на рисунке поля. Подворотни находятся на пятых клетках от угла (считая сам угол), обозначенных числом `2`.
- Переходы работают в обе стороны: `4 ↔ 44`, `8 ↔ 16`, `20 ↔ 28` и `32 ↔ 40` (индексы внешнего круга).
- Если фишка заканчивает движение на подворотне, она автоматически перемещается на парную клетку. Переход не требует отдельного кубика и срабатывает один раз: фишка не перебрасывается сразу обратно.
- При проходе через подворотню без остановки переход не срабатывает. После переноса фишка продолжает обычное движение по кругу.
- Прогресс круга учитывает перенос вперёд или назад на восемь клеток. Фишки соперника на клетке назначения отправляются в центральную тюрьму.

### СИЗО

- Прямые стрелки на внешнем круге ведут в СИЗО соответствующего угла; это отдельные входы, не связанные с подворотнями.
- За один ход игрок может сделать только один переход внутри СИЗО, в том числе если дубль дал дополнительный бросок.
- Для выхода с первой, второй и третьей клетки требуется соответственно `1`, `2` и `3`.
- Кубики расходуются по убыванию и в СИЗО: сначала применяется большее доступное значение. Например, при `2` и `1` нельзя сначала пройти с первой клетки по единице, а затем со второй по двойке.
- После третьей клетки фишка возвращается на внешний круг через две клетки после входа. Если после выхода осталось меньшее значение кубика, его можно сразу использовать для обычного движения по внешнему кругу.

### Хата

- После полного круга фишка входит в собственную дорожку из четырёх домашних клеток.
- Внутри хаты требуется точное значение кубика; перебор запрещён.
- Фишки в хате нельзя сбить, соперники не могут войти в чужую хату.
- Фишка считается заведённой после достижения четвёртой домашней клетки.

## Порядок хода

- По кнопке «Бросить кубики» два объёмных кубика падают на игровую доску, вращаются, отскакивают и останавливаются выпавшими гранями вверх.
- Пока кубики летят, повторный бросок, постановка и перемещение фишек недоступны. Кнопка «Пропустить анимацию» сразу завершает тот же бросок, не меняя его результат.
- После остановки следующий доступный кубик выделен, использованный приглушён. Последний результат остаётся на доске даже при автоматическом пропуске хода.
- При включённом системном уменьшении движения полёт заменяется коротким показом результата. Если WebGL недоступен, используются объёмные кубики на CSS.
- Для постановки новой фишки из руки требуется `6`.
- Если выпала шестёрка, игрок выбирает: поставить новую фишку либо передвинуть уже стоящую.
- Обычные значения кубиков расходуются по убыванию. Если большее значение применить нельзя, игра переходит к следующему применимому.
- Если допустимых действий нет, ход завершается автоматически.
- Дубль даёт дополнительный бросок после использования всех применимых значений.
- Две шестёрки позволяют поставить две фишки, выполнить обычные движения либо вывести одну фишку из тюрьмы прямо на старт.

## Столкновения

- Если фишка останавливается на обычной клетке с фишками соперника, все чужие фишки с этой клетки отправляются в центральную тюрьму.
- Несколько фишек одного игрока могут находиться на одной клетке.

## Победа

Игрок выигрывает, когда все 4 его фишки достигли последней клетки собственной хаты. После победы игровые действия блокируются до начала новой партии.
